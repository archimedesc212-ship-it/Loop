# LOOP feature-scope review — 10 November 2026

The previous 120-item brainstorm was checked against LOOP's documented basic product scope and the current source tree. The active roadmap now contains **102 music-focused features**. **18 proposals were removed** from the active scope.

The retained capabilities support music discovery, search, recommendations, playback, playlists, artist/release information, charts where a reliable data source exists, listener privacy, history and platform operations. The scope keeps the normal listener experience focused on Home, Discover, Assistant, Search, Library and Settings, with artist/admin pages gated by role.

Removed proposals mainly fell into five groups: (1) a marketing campaign feature; (2) lyrics search/display before a licensed lyrics provider exists; (3) controls that LOOP cannot reliably apply to third-party embedded players; (4) complex social-network functions such as friend feeds, listening rooms, comments and reaction systems; and (5) low-value chart-history/notification/layout extras that add operational complexity without improving the core listening journey.

No existing application functionality was deleted as part of this scope review. The removed items were removed from the active feature roadmap only. The original source code and existing modules remain intact.

See [LOOP_FEATURE_ROADMAP.md](LOOP_FEATURE_ROADMAP.md) for the 102 retained features and their honest implementation status. The roadmap is not a claim that all retained features are complete.
